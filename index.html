Détails techniques
  • RAG optimisé : recherche hybride dense + BM25 (70/30) et reranking cross-encoder.
  • Résultats par modèle : Qwen2.5-7B 60→78%, Llama 3.1-8B 49→75%, Mistral-7B 16→64% (FT+RAG).
  • Le RAFT dégrade les performances dans la majorité des cas : analyse critique documentée.
  • API REST FastAPI exposant 3 agents (similarité, MMR, arbitrage) avec repli sur le web en cas de désaccord.
